# Lexo

Nyelvtanulást támogató webalkalmazás saját szógyűjteményekhez, gyakorló módokhoz és osztályszintű használathoz.

> Ez egy készülő projekt. A funkciók egy része még fejlesztés alatt áll, ezért jelenleg lehetnek hiányzó elemek, félkész megoldások és változó működésű részek.

[Live Demo](https://lexo.hobbycode.link/)

## Áttekintés

A Lexo egy Next.js alapú alkalmazás, amiben a felhasználók:

- saját szókészleteket és mappákat hozhatnak létre,
- kifejezéseket kezelhetnek manuálisan vagy importtal,
- különböző játék módokban gyakorolhatnak,
- kedvenceket és közösségi gyűjteményeket böngészhetnek,
- tanári nézetben osztályokat kezelhetnek, feladatokat oszthatnak, és nyomon követhetik a fejlődésüket,
- Azure-alapú fordítási, nyelvfelismerési és felolvasási funkciókat használhatnak.

## Technológiai stack

- `Next.js 15` App Routerrel
- `React 19`
- `TypeScript`
- `Material UI 7`
- `NextAuth v5 beta`
- `Drizzle ORM` + `drizzle-kit`
- `PostgreSQL`
- `SWR`
- `Zod`
- Azure Cognitive Services a nyelvi funkciókhoz
